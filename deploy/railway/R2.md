# Dograh on Railway — Cloudflare R2 storage

Replace bundled MinIO with R2 for call recordings, transcripts, and library uploads.

## 1. Create bucket

Bucket name: `dograh-voice-audio` (already created in Cloudflare if you followed the setup run).

## 2. Create R2 API token

1. Open [R2 overview](https://dash.cloudflare.com/?to=/:account/r2/overview)
2. **Manage R2 API Tokens** → **Create API token**
3. Permissions: **Object Read & Write** on `dograh-voice-audio`
4. Save **Access Key ID** and **Secret Access Key**

## 3. Account ID

For this deployment: `f4c10eea82683bea7d7cb1af3bf045e3`

S3 API endpoint: `https://f4c10eea82683bea7d7cb1af3bf045e3.r2.cloudflarestorage.com`

## 4. CORS policy

Apply `r2-cors.json` so the UI can fetch presigned URLs from the browser:

```bash
npx wrangler r2 bucket cors set dograh-voice-audio --file deploy/railway/r2-cors.json
```

Or paste the JSON in the bucket **Settings → CORS Policy** in the dashboard.

Update `AllowedOrigins` if your UI domain changes.

## 5. Railway API variables

Set on the **api** service (remove MinIO-specific vars after verifying):

| Variable | Value |
|---|---|
| `ENABLE_AWS_S3` | `true` |
| `S3_BUCKET` | `dograh-voice-audio` |
| `S3_REGION` | `auto` |
| `S3_ENDPOINT_URL` | `https://f4c10eea82683bea7d7cb1af3bf045e3.r2.cloudflarestorage.com` |
| `S3_SIGNATURE_VERSION` | `s3v4` |
| `S3_ADDRESSING_STYLE` | `path` |
| `AWS_ACCESS_KEY_ID` | R2 access key |
| `AWS_SECRET_ACCESS_KEY` | R2 secret key |

Redeploy **api**, run a test call, confirm logs show `Successfully uploaded mixed audio`.

## 6. Remove MinIO (optional)

After recordings work, delete or stop the **minio** Railway service.
